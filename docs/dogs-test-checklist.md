# Dogs test checklist

Goal: nine dogs can be picked as the buddy, and they act like dogs: they talk like dogs and play with a bone.

Get the build the same way as before: download the `DesktopBuddy-win-x64` artifact from the pull request's latest **build** run. Exit the old version first.

| # | What to do | What should happen | Pass? |
| --- | --- | --- | --- |
| 1 | Open Settings | The list that used to be called **Cat** is now **Buddy**, and ends with nine dogs: Mocha, Juniper, Domino, Pip, Toast, Clover, Waffles, Hazel and Peaches. There is a new option, **Play with a bone (dogs)**, ticked | |
| 2 | Pick each dog in turn | The preview and the buddy on the taskbar change straight away, and the tray icon shows the dog's head. Fur colour and pattern are greyed out | |
| 3 | Watch a dog for a few minutes | It walks, sits, scratches and loafs like the cats do, and now and then plays with its bone: chews it lying down, tosses it up and catches it, or does a play bow and then trots off with the bone in its mouth | |
| 4 | Make the PC busy while it walks | It gallops with its tongue out and sweats, the same as the cats | |
| 5 | Click a dog a few times, or let it ask for belly rubs | It shows its belly with its head upside down and tongue out. The bubbles sound like a dog ("Belly rubs?", "Best human ever!") instead of purring | |
| 6 | Let it fall asleep, then click it | It grumbles in a dog's voice ("Wuf?!") | |
| 7 | Tick **Pause walking** | It can still chew and toss the bone, but never trots off with it | |
| 8 | While it has the bone, untick **Play with a bone (dogs)** | It drops the bone and sits at once, and never picks it up again until you tick it | |
| 9 | Start a focus timer | No bone play during the session | |
| 10 | Switch back to a cat | The cat never gets the bone, and talks like a cat again | |
| 11 | Restart the app | The dog you picked and the bone setting are remembered | |
