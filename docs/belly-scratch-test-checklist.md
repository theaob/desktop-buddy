# Belly scratch requests test checklist

Goal: every so often the cat rolls onto its back and asks for belly scratches. Scratch it and it purrs; ignore it and it sulks for a moment.

Get the build the same way as before: download the `DesktopBuddy-win-x64` artifact from the pull request's latest **build** run. Exit the old version first.

The cat asks after 12 to 25 minutes of you using the PC (time away doesn't count). Open **Diagnostics** from the tray menu to see the **Belly ask in** countdown, so you know when to look.

| # | What to do | What should happen | Pass? |
| --- | --- | --- | --- |
| 1 | Open Settings | There is a new option, **Ask for belly scratches now and then**, ticked | |
| 2 | Keep working until Belly ask in reaches 0 | The cat stops what it's doing, lies on its back wiggling its paws, and a bubble asks for belly scratches (the wording varies) | |
| 3 | Click the cat while it's asking | It rolls around happily, a bubble says thanks or purrs, then it sits up with hearts | |
| 4 | Next time it asks, leave it alone | After about 15 seconds the bubble says something huffy ("Hmph."), the cat turns its back to the mouse and lies in a loaf for a few seconds, then carries on as normal | |
| 5 | While it's sulking, click it | It forgives you and shows hearts | |
| 6 | While it's asking, drag it away | The ask bubble goes away; it hangs and drops as usual, with no sulk | |
| 7 | Step away from the PC for a few minutes | Belly ask in doesn't count down while you're away | |
| 8 | Click the cat three times quickly to roll it over yourself | Belly ask in jumps back to 12 minutes or more, since it just got its rub. It sits up afterwards without hearts | |
| 9 | Start a focus timer | The cat never asks during a session, and if it was asking it stops straight away. The countdown keeps showing | |
| 10 | Let a break reminder show, with Belly ask in near 0 | It waits until the reminder bubble is gone before asking | |
| 11 | Untick the option in Settings | Diagnostics shows Belly ask in: off, and the cat never asks | |
| 12 | Repeat 2 and 3 with a couple of the new cats from the Cat list | They use their own on-their-back drawings | |
