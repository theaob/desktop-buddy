# Wake-up reaction test checklist

Goal: waking a sleeping cat yourself gets a reaction, for every cat.

Get the build the same way as before: download the `DesktopBuddy-win-x64` artifact from the pull request's latest **build** run. Exit the old version first.

Tip: set "Nap after" to 1 minute in Settings so you don't wait long.

| # | What to do | What should happen | Pass? |
| --- | --- | --- | --- |
| 1 | Leave the PC until the cat naps, then come back and move the mouse | The cat keeps sleeping for about 20 to 45 seconds, then wakes slowly on its own like before (blink, stretch, yawn) | |
| 2 | Let it nap again, come back and click the cat | Its snot bubble pops, it jumps on the spot with its fur on end, turns to glare toward the mouse with sleepy eyes, yawns, then sits. A bubble says something grumpy like "Hey! I was napping." | |
| 3 | Click it a few more times while it grumbles | No hearts until it has sat back up | |
| 4 | Wait for it to doze sitting up (eyes shut, snot bubble), then click it | Same grumpy wake-up as step 2 | |
| 5 | Let it nap, then grab and drag it instead of clicking | It dangles as usual and a bubble says something like "Hey! Put me down!" | |
| 6 | Start a focus timer, then click a napping cat | It still jumps and glares, but the focus countdown stays in the bubble instead of a grumpy line | |
| 7 | In Settings, turn off **Grumble when woken up**, then click a napping cat | No jump and no bubble: it just wakes slowly (blink, stretch, yawn) | |
| 8 | Turn the option back on and repeat step 2 with a few different cats from the **Cat** list | Each one does the reaction in its own style | |
