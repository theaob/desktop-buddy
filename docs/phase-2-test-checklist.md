# Phase 2: useful, livelier buddy test checklist

Goal: a cat that feels alive and earns its place with a few small helpers.
Gate to phase 3: you keep it running for a week and nothing below is broken.

Get the build the same way as before: download the `DesktopBuddy-win-x64` artifact from the pull request's latest **build** run. Exit the old version first.

| # | What to do | What should happen | Pass? |
| --- | --- | --- | --- |
| 1 | Watch it for a few minutes | Besides walking and sitting, it sometimes scratches with a back leg raised behind its head | |
| 2 | Keep watching | Now and then a yarn ball rolls in; the cat chases it and bats it along the taskbar | |
| 3 | Click the yarn ball | It rolls away from the side you clicked | |
| 4 | Leave the mouse somewhere on the cat's monitor | Sometimes the cat walks along the taskbar to stay under the cursor | |
| 5 | Rest the cursor a little above the cat | It crouches and wiggles, then leaps at the cursor and lands back on the taskbar. It waits a while before hunting again | |
| 6 | Open an app, drag a window and let go, or get a flashing taskbar button | The cat turns toward that window and looks up for a moment | |
| 7 | Grab the cat near its head and drag | It hangs upright by the scruff | |
| 8 | Grab the cat low on its body and drag | You hold it under the belly, legs and tail dangling | |
| 9 | Right-click the cat or the tray icon, Start focus timer | A bubble above the cat counts down; click the bubble to hide it. When it ends the cat hops with hearts and says well done | |
| 10 | Start a focus timer, then Stop focus timer | The countdown disappears; the cat doesn't follow or hunt the mouse during a session | |
| 11 | In Settings, set break reminders to 5 min and keep working | After 5 minutes of use a bubble suggests a break. Stepping away for 5 minutes resets the count | |
| 12 | Run something heavy (a big build, a CPU stress test) | Within a few seconds the cat hurries and a sweat drop appears; both stop when the load ends | |
| 13 | Turn off each new option in Settings | Mouse chasing, window watching, yarn play and the CPU reaction each stop | |
| 14 | Leave it running for a workday | Task Manager shows it under 1% CPU | |

Diagnostics now also shows CPU load, the focus timer, and minutes of use since the last break.
