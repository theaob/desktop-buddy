# Birds test checklist

Goal: ten birds can be picked as the buddy, and they act like birds: they hop, fly when in a hurry, peck, sing, flap and chirp.

Get the build the same way as before: download the `DesktopBuddy-win-x64` artifact from the pull request's latest **build** run. Exit the old version first.

| # | What to do | What should happen | Pass? |
| --- | --- | --- | --- |
| 1 | Open Settings | The **Buddy** list ends with ten birds: Ember, Blueberry, Acorn, Sunny, Kiwi, Skye, Inky, Slate, Nugget and Rosehip | |
| 2 | Pick each bird in turn | The preview and the buddy on the taskbar change straight away, and the tray icon shows the bird's head. Fur colour and pattern are greyed out | |
| 3 | Watch a bird for a few minutes | It hops along instead of walking, preens under its wing, and now and then pecks at seeds, sings with notes floating up, or shakes out its wings | |
| 4 | Make the PC busy while it moves | It flies low along the taskbar with a wingbeat, and sweats | |
| 5 | Click a bird a few times, or let it ask for scritches | It flops over to sunbathe. The bubbles sound like a bird ("Head scritches?", "Tweet! Thank you!") | |
| 6 | Let it fall asleep, then click it | It fluffs up to sleep (later with its head tucked into its back), then grumbles in a bird's voice ("Cheep?!") | |
| 7 | Pick it up and drop it | It dangles with its wings out, flaps as it falls, and lands with its wings swept forward | |
| 8 | Switch back to a cat or a dog | No pecking or singing, and it talks like a cat or dog again | |
| 9 | Restart the app | The bird you picked is remembered | |
